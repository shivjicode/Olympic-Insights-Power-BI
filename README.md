# Olympic Insights Using Data Analytics

## Project Overview

This Power BI project analyses historical Olympic data across countries, athletes, sports, host nations, gender and age groups.

## Key Findings

- Analysed 64 Olympic editions.
- The dataset contains approximately 156K athletes and 112 sports.
- A total of 20,654 medal records were analysed.
- The United States leads the overall medal ranking.
- Michael Phelps is the most decorated athlete with 28 medals.

## Dashboard Pages

1. Global Medal Overview
2. Country Performance Analysis

4. Sport & Event Analysis
